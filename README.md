## Project Overview
A simple HTML project inspired by my very first reading journey back in 2016.  
This project presents a synopsis of *The Best of Sherlock Holmes*.


## Background
In 2016, I woke up one day, and decided to get into reading. That's when I ordered a book from Amazon. It was none other than one of the greatest creations, Sherlock Holmes. To be honest, starting with a mystery novel was tough since you have to keep up with the clues. But, I really enjoyed it. I also reread it for a synopsis that's when I realised I could put my HTML skills to use.
<br/><br/>
Umm, it's a small, subpar project but, very personal for me. This folder was lying in a corner of my drive so, I decided to dust it off and share it over here.
